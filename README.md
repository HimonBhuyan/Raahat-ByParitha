## 🏛️ About The Brand

**Raahat ByParitha** is a luxury bespoke menswear maison specializing in handcrafted royal wedding sherwanis, black-tie embellished tuxedos, traditional South Indian pure silk ensembles, and contemporary Indo-Western cuts.

---

## ✨ Key Features

- **Haute Couture Lookbook**: Category-filtered gallery (Weddings, Tuxedos, Bandhgalas, Indo-Western) with interactive Quick View modals.
- **Interactive Atelier Configurator**: Step-by-step bespoke silhouette, fabric, and embroidery selector with real-time price estimation (in ₹ INR) and craft timeline calculation.
- **The Bespoke Journey**: Architectural 40-point measurement guide and textile archive (Mulberry raw silk, Italian silk velvet, Super 150s Merino wool, Zardozi bullion wire).
- **VIP Concierge & Direct WhatsApp Desk**: Seamless booking system with direct WhatsApp message integration for consultation scheduling.
- **100% Fully Responsive**: Fluid on all screen sizes (mobile, tablet, desktop) with slide-out navigation drawer, horizontal touch-scrolling filters, and touch-optimized controls.

## 🚀 Running Locally

### Option 1: PHP Built-in Server
```bash
php -S localhost:8000
```
Open [http://localhost:8000](http://localhost:8000) in your browser.

### Option 2: XAMPP (Apache)
1. Place repository in `c:/xampp/htdocs/Raahat byPa/` (or your Apache web root).
2. Start Apache in XAMPP Control Panel.
3. Open [http://localhost/Raahat%20byPa/](http://localhost/Raahat%20byPa/) in your browser.
